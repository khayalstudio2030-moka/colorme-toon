# colorme-toon
موقع يقدر يخلي كل عميل يعمل صورة كارتون بستايل coloring book لطفله بنفسه من خلال رفع صورة الطفل علي الموقع وتحديد هواياته والحاجات اللي بيحبها ومن خلال المعلومات اللي العميل بيدخلها الموقع بيولد صور للطفل بالذكاء الاصطناعي ويكون فيها شكل الطف وهو بيعمل هواياته ومع الحاجات اللي بيحبها
